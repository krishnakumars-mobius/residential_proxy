    Requests by day

    How this report is calculated

    • The current period is the From and To dates in the filters. Without them it is the last 30 days, ending today (UTC).
    • The previous period has the same number of days and ends the day before the current period starts.
    • Both periods use the same domain, service, agent, result, HTTP status and token filters.
    • Change is the percentage difference from the previous period; success rate change is in percentage points.

    Requests - GET

      Coordinator request fields

      Every example sends a JSON body to POST /fetch and authenticates with Authorization: Bearer YOUR_TOKEN.

      • url is the target URL. service is requests, selenium, nodriver, or playwright.
      • headers passes headers to the target site (Selenium currently honors User-Agent only). The coordinator bearer token remains in the HTTP Authorization header.
      • For requests POST jobs, use http_method: "POST" and either json or data. Browser services currently navigate with GET.
      • Requests sessions use session: true to create and session_id to reuse; sessions are not supported by browser services.
      • Responses include content, content_type, and content_encoding. JSON content is an object, text/HTML is text, and image/PDF/Excel bytes are base64.
      Fetch response content and save it by content type.
